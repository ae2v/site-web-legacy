# 13 — Skill Lovable optionnelle : AE2V UX + Brand Audit

> Peut être transformée en Workspace Skill Lovable si cette fonctionnalité est utilisée.

## Name

```text
ae2v-ux-brand-audit
```

## Description

Utiliser lorsqu'une page, un flow ou un composant AE2V doit être audité, créé ou finalisé. Vérifie simultanément l'ergonomie, l'accessibilité et la conformité forte à la charte AE2V.

## Instructions

```text
Audit the target using two axes.

AXIS A — UX:
1. system status feedback
2. real-world language
3. one primary action
4. recognition over recall
5. consistency
6. error prevention
7. cancel/back/edit
8. mobile/touch/form quality
9. hierarchy before decoration
10. recovery/help

AXIS B — AE2V BRAND:
- red dominant
- acid green meaningful
- hard/square geometry
- impactful typography
- crystals/triangles
- dot clouds
- crosses/markers
- diagonal lines
- graphic underlines
- paper/tape labels
- controlled grain
- asymmetric editorial composition

For each axis:
PASS / WARN / FAIL.

Never recommend generic SaaS visuals as a simplification.

If brand decoration reduces readability, interaction, focus visibility or task completion:
preserve the brand but reduce/reposition the decoration rather than removing the identity entirely.

Return:
- top 3 UX fixes
- top 3 brand fixes
- exact components/routes affected
- what not to change
- verification checklist.
```
