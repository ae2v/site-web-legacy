# Ergonomie

## Nielsen Norman Group — 10 Usability Heuristics

https://www.nngroup.com/articles/ten-usability-heuristics/

Principes utilisés :

- visibility of system status ;
- match system / real world ;
- user control ;
- consistency ;
- error prevention ;
- recognition over recall ;
- flexibility ;
- minimalist focus ;
- error recovery ;
- help.

## WCAG 2.2

https://www.w3.org/TR/WCAG22/

Critères particulièrement pertinents :

- focus not obscured ;
- target size minimum ;
- redundant entry ;
- accessible authentication.

## W3C — What's New in WCAG 2.2

https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/

## GOV.UK Design System — Error message

https://design-system.service.gov.uk/components/error-message/

Principes :

- dire ce qui ne va pas ;
- dire comment corriger ;
- ne pas vider les champs ;
- messages spécifiques.

## GOV.UK — Labels and legends as headings

https://design-system.service.gov.uk/get-started/labels-legends-headings/

Principe :

- pour les parcours complexes, une information / décision / question clairement focalisée par étape.

## Baymard — Avoid Apply buttons

https://baymard.com/blog/checkout-usability-apply-buttons

Principe :
