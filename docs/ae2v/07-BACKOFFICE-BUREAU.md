# 2. Ergonomie du bureau

Le bureau doit être un **outil de travail**, pas une vitrine de la charte.

## Règle

La charte s'exprime par :

- rouge ;
- noir ;
- titres ;
- traits ;
- états ;
- repères.

Le décor lourd est limité.

## Priorité

```text
À TRAITER > KPI > GRAPHIQUES
```

---

# 3. Dashboard

Exemple :

```text
SAMEDI 8 AOÛT              2026–2027

182      4       21       3
ADH.     EVENTS   CMD      STOCKS BAS

À TRAITER
→ 8 commandes à préparer
→ 3 adhésions en attente
→ 2 remboursements
```

Les valeurs doivent être réelles.

---

# 4. Dashboard ergonomique

Chaque item « À traiter » mène directement à une liste déjà filtrée.

Exemple :

```text
8 COMMANDES À PRÉPARER
```

clic :

```text
/bureau/commandes?status=PREPARING
```

---

# 5. Adhérents

Filtres :

- année ;
- statut ;
- recherche.

Actions fréquentes visibles.

Actions rares dans menu secondaire.

Action destructrice :

- confirmation ;
- motif si nécessaire ;
- audit.

---

# 6. Création événement

Ne pas afficher 30 champs d'un coup.

Découper par blocs :

```text
1. Contenu
2. Date / lieu
3. Billetterie
4. Capacité
5. Publication
```

Sur mobile / petit écran bureau, ces étapes peuvent être séquentielles.

---

# 7. Scanner

Interface dédiée, sans sidebar lourde.

```text
[ ← ]   SCANNER

     caméra

RÉSULTAT
```

Résultat plein écran :

```text
✓ VALIDE
```

ou :

```text
! DÉJÀ SCANNÉ
```

Le volontaire ne doit pas parcourir une table pour valider l'entrée.

---

# 8. Boutique opérationnelle

Vue commande :

```text
À PRÉPARER
PRÊTES
TERMINÉES
ANNULÉES
```

Favoriser les queues de travail, pas seulement un tableau générique.

---

# 9. Stock

Alerte claire :

```text
STOCK BAS
SWEAT M — 2 RESTANTS
```

CTA :

```text
AJUSTER LE STOCK
```

---

# 10. Exports

Un export doit expliquer :

- ce qu'il contient ;
- période ;
- filtres appliqués ;
- données personnelles incluses.

Ne pas exporter tout par défaut.
